# Predicting Respiratory Hospital Admissions from Air Quality: A Multi-City Model Comparison

A data mining project that compares Linear Regression, Decision Tree, Support Vector Machine (SVM) and a Deep Neural Network (MLP) for predicting daily respiratory hospital admissions from air quality and weather measurements in eight cities.

> **The main dataset is synthetic.** Our audit ([docs/DATA_AUDIT.md](docs/DATA_AUDIT.md)) shows it was generated by a script, not collected from hospitals and monitoring stations. This project is a **methodological comparison of models on a fixed benchmark**. It makes no claims about real-world health effects.

---

## At a Glance

| | |
|---|---|
| **Task** | Regression (daily admission count) and classification (high-admission "spike" day) |
| **Main dataset** | *Global Air Quality and Respiratory Health Outcomes* (Kaggle), 88,489 rows, 8 cities |
| **Models** | Linear Regression (baseline), Decision Tree, SVM, MLP. Optional extension: Random Forest |
| **Primary metric** | RMSE (also MAE, R², and PR-AUC for spike detection) |
| **Optional add-on** | A real air quality dataset containing Delhi for a context check (see below). Not needed for the main results |
| **Key principle** | The test set is used once. Models are compared with confidence intervals and a pre-set equivalence margin |

## Research Questions

1. **RQ1.** Which model (Linear Regression, Decision Tree, SVM, MLP) most accurately predicts daily respiratory hospital admissions from air quality and weather features?
2. **RQ2.** Does model performance, or the pollution–admissions relationship, differ across cities?
3. **RQ3.** Which features drive the predictions?
4. **RQ4.** Can the models flag high-admission days (early warning)?

## Dataset

- **Source:** https://www.kaggle.com/datasets/tfisthis/global-air-quality-and-respiratory-health-outcomes
- **Target:** `hospital_admissions` (daily count, 0–25)
- **Features:** `aqi, pm2_5, pm10, no2, o3, temperature, humidity`, plus `city` (8 cities)
- **Also present, not used in the main analysis:** `date`, `population_density`, `hospital_capacity`

What the audit found (details in [docs/DATA_AUDIT.md](docs/DATA_AUDIT.md)):

- The `date` column is a row counter with a random city per row, so there is **no time series**. Time-series models (Prophet) and lag features are not used.
- Only **PM2.5** relates to admissions (correlation 0.39). All other features are at about 0.
- All cities look identical (mean PM2.5 about 35, mean admissions about 8), so a "high-pollution vs low-pollution city" comparison is **not supported by this dataset**.

## Approach

| Step | What happens |
|---|---|
| 1. Validate and audit | Check the data, document the findings above |
| 2. *(Optional)* Real-data reference check | Compare the main dataset with a real air quality dataset containing Delhi (context only) |
| 3. Split | 80/20 stratified train/test split. Test set used once |
| 4. Baselines | Mean predictor, PM2.5-only linear model |
| 5. Models | Tune 4 model families with 5-fold CV on the training set |
| 6. Evaluate | Test-set metrics with bootstrap confidence intervals, paired comparisons |
| 7. City analysis | Pooled vs per-city models, slope comparison, leave-one-city-out |
| 8. Spike task | Same models as classifiers for "high-admission day" |
| 9. Interpret | Permutation importance, partial dependence |

| Model | Regression | Spike classification |
|---|---|---|
| Linear Regression | OLS (and Poisson GLM) | Logistic Regression |
| Decision Tree | Regression tree | Classification tree |
| SVM | SVR (RBF kernel) | SVC (RBF kernel) |
| Deep Neural Network | MLP | MLP with sigmoid output |

Full step-by-step plan: [docs/METHODOLOGY.md](docs/METHODOLOGY.md).

## Evaluation Metrics

| Metric | Use |
|---|---|
| **RMSE** (primary) | Penalises large misses (missed spikes) |
| **MAE** | Average error in admissions per day |
| **R²** | Share of variance explained |
| **Poisson deviance** | Count-appropriate secondary metric |
| **PR-AUC, F1, recall** | Spike detection (about 12% of days are spikes) |

Models are called "different" only if the gap exceeds a pre-set margin. Otherwise they are reported as tied and the simpler one is recommended ([docs/EVALUATION.md](docs/EVALUATION.md)).

## Expected Outcomes

- All models that use PM2.5 reach a similar R² of about 0.15, which is the ceiling for this data.
- SVM and MLP are not expected to beat Linear Regression by a meaningful margin. That is a valid, reportable finding.
- The PM2.5 slope (about 0.1 admissions per µg/m³) is expected to be the same in every city.
- PM2.5 is the only important feature.

## Optional: Real-Data Reference Check

The original proposal claimed Delhi is a high-pollution city and London a low-pollution one. In the main dataset that claim cannot be tested, because the data is synthetic and both cities have the same pollution levels. As an **optional add-on**, one real air quality dataset that includes Delhi can be compared with the main dataset on pollution levels, the AQI–PM2.5 relationship, autocorrelation and seasonality. This is context only. It does not feed into any model, the datasets are **not merged**, and no admissions are predicted for real cities. It can be done at any time after the data audit, or skipped without affecting the main results (details in [docs/METHODOLOGY.md](docs/METHODOLOGY.md), Step 2B).
